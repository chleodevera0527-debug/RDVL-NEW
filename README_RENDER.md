R.DEVERA Truck Monitor production deployment

Repository root must contain app.py, requirements.txt, render.yaml, and .python-version.

Render build command:
python -m pip install --upgrade pip && python -m pip install -r requirements.txt

Render start command:
python -m gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --threads 4 --timeout 120

Required production environment variables:
DATABASE_URL: supplied by Render Postgres through render.yaml
APP_SECRET: generated by Render
COOKIE_SECURE: 1
ALLOW_DEFAULT_ADMIN: 0
ADMIN_USERNAME: admin
ADMIN_PASSWORD: set privately in Render

Local development uses SQLite when DATABASE_URL is absent. For a local default admin, set ALLOW_DEFAULT_ADMIN=1. For production, keep it 0 and provide ADMIN_PASSWORD.

Do not commit .env files or production secrets.

Production timezone: `Asia/Manila` (Philippines). All server-generated timestamps and dashboard clocks use Philippine time.


Milestone event handler patched: SQL UPDATE cursor rowcount is now captured correctly before checking the affected row count. WSGI exceptions are logged server-side without exposing internal details to users.
